# MP-RAG
MP-RAG: Enhancing Retrieval-Augmented Generation for Question Answering via Multi-Perspective Collaborative Framework

by Jingling Yuan, Hong Yu.

# Usage:

Python 3.11.10

PyTorch 2.6.0, torch_npu 2.6.0, Transformers 4.53.1, vLLM 0.7.3, vLLM-Ascend 0.7.3rc1, FlashRAG 0.3.0.dev20251126, FAISS 1.8.0, NumPy 1.26.4.

# Experimental environment:

Browser-based cloud development environment on the Huawei Ascend platform, EulerOS 2.0 (SP10), Kunpeng-920 CPU, Huawei Ascend 910B4 AI processor (NPU) with 32 GB HBM, 1.5 TiB RAM, CANN 8.2.RC1, Ascend Driver 25.5.1.

# Reference:

Jingling Yuan and Hong Yu. MP-RAG: Enhancing Retrieval-Augmented Generation for Question Answering via Multi-Perspective Collaborative Framework. Manuscript under review, 2026.
